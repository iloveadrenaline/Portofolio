# Andrei's Portfolio ✦
<img width="1877" height="930" alt="image" src="https://github.com/user-attachments/assets/93368f93-7470-49ff-92e8-82709c7c31af" />

A modern, interactive portfolio showcasing Andrei's electronics and hardware projects.

## Features

- **Responsive Design**: Optimized for desktop and mobile devices
- **Interactive Elements**: Hover effects, particle animations, and easter eggs
- **Project Discovery**: Filter projects by technology and open a random project
- **Project Context**: Status, category, year, and previous/next navigation on project pages
- **About / Contact**: Public profile summary with email, GitHub, LinkedIn, and Ko-fi actions
- **Project metadata**: Each project exposes its category, status, year, and technology stack
- **Skills / Stack**: Hardware, firmware, software, and tools grouped in a responsive skills panel
- **Command Palette**: Terminal-style interface with fun commands (Ctrl+K to open)
- **Visual Modes**: A temporary scan effect available from the command palette
- **Accessibility**: Keyboard-friendly controls and reduced-motion support
- **Performance**: Optimized loading with preconnects, preloads, deferred scripts, and responsive behavior

## Technologies Used

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Fonts**: Google Fonts (Special Gothic Condensed/Expanded One)
- **Icons**: Custom SVG cursor hands
